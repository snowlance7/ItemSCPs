# ItemSCPs Mod

## Description

Adds a bunch of SCP Items to the game. You can toggle which SCP's to enable or disable to customize your experience.

## Currently Added SCP's

- SCP-005
- SCP-012
- SCP-1025
- SCP-1079
- SCP-207
- SCP-268
- SCP-3482
- SCP-420-J
- SCP-498
- SCP-500
- SCP-689
- SCP-714
- SCP-735
- SCP-983

## Planned SCPs
